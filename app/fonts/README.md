# Vendored Fonts

Sombreado Floripa vendors the webfont assets used by the Soft Tech design
system so production pages do not depend on runtime font requests.

- Newsreader: `newsreader-*-variable.woff2`
- Hanken Grotesk: `hanken-grotesk-*-variable.woff2`

Both families are distributed under the SIL Open Font License. The license text
for each family is stored beside the font files.
