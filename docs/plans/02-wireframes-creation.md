# 02 - Wireframes Creation

## Goal

Create low-fidelity mobile wireframes for the complete v1 onboard flow before coding the app.

## Inputs

- `docs/brand-guide.md`
- `docs/product-decisions.md`
- `CONTEXT.md`

## Work

- Wireframe the location request screen.
- Wireframe geolocation denied and manual fallback states.
- Wireframe nearby route candidate selection.
- Wireframe selected route confirmation with a compact map area.
- Wireframe the advisory result with the bus orientation diagram.
- Wireframe no candidates, API error, slow loading, and withheld/off-route states.
- Decide the minimum screen copy for each state.

## Deliverable

- A wireframe document in `docs/wireframes-v1.md`.

## Acceptance Criteria

- Every core v1 state has a sketched layout and primary action.
- The result screen makes the seat-side recommendation obvious within a few seconds.
- Empty and failure states are designed, not left as generic errors.
