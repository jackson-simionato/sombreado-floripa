# 01 - Branding Refinement

## Goal

Define a small brand guide for Sombreado Floripa before UI implementation starts.

## Inputs

- `CONTEXT.md`
- `docs/product-decisions.md`
- References: Airbnb, Anthropic, Claude Code

## Work

- Define the visual principles for the playful sunny brand.
- Choose a first-pass color direction for sun, shade, surfaces, text, success, warning, and error states.
- Choose typography direction and spacing principles for a mobile-first web app.
- Define copy rules for Brazilian Portuguese: short, local, direct, friendly, and honest about limitations.
- Define how diagrams should behave: bus orientation, sun/shade side, and accessible non-color cues.
- Capture "do not do" rules, such as mascot-heavy visuals, dense transit-control styling, or misleading guaranteed-shade language.

## Deliverable

- A brand guide in `docs/brand-guide.md`.

## Acceptance Criteria

- A designer or engineer can create wireframes without re-deciding tone, visual references, or copy posture.
- The guide clearly explains how Sombreado differs from a generic map app or government service.
